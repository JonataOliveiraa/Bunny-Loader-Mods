# Changelog

## 1.0.2

- Summon staffs and other aimed weapons can be placed on the base: tapping the
  base puts them on display instead of summoning or attacking.
- Tools: a quick tap on the base puts the tool on display; holding the finger
  mines as usual.
- Placing an item no longer plays its use animation.
- The granite base shows the granite icon under the finger.

## 1.0.1

- Fixed for mobile: the base loads, tapping it places and takes items, and the
  displayed item is drawn.
- Hitting a base with a pickaxe only drops the item, without breaking the base
  on the same hit.

## 1.0.0

- Port of Item Display Base 0.9 to Bunny Loader: marble and granite Display
  Bases, the displayed item saved with the world, glitter, outline, bright
  drawing and light settings, and multiplayer sync.
- Settings and names in 12 languages.
