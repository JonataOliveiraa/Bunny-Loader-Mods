# NPC Unlock Announcer

Never miss a new villager again! An RPG-style banner slides in at the top of
the screen whenever a Town NPC or town pet moves into your world, with its
head, its name and a witty subtitle.

## Banner styles

- **Classic**: black and gold frame.
- **Modern**: neon frame with animated colors.
- **Corruption**, **Crimson**, **Wood** and **Jungle**: biome themed banners.

## Settings

| Setting | What it does |
| --- | --- |
| Style | The banner look. |
| Sound | Magic Ding, Coins, Max Mana, Research, Chest Unlock, Crimson, Knock, Jungle, Corruption or none. |
| Volume | Volume of the announcement sound. |
| Duration | How many seconds the banner stays on screen. |
| Frequency | First Time: only the first arrival of each NPC in the world. Every Time: every arrival. Set Amount: up to **Max Per NPC** times. |
| Preview | Shows a test banner. |

Each world remembers which NPCs were already announced. Every vanilla Town
NPC has its own subtitles; other NPCs use their name and a default subtitle.
