This mod adds an intuitive interface with various tools that allow you to quickly test game behaviors.

## Tools

- Switch Difficulty
- Entity Despawner
- Hitboxes
- Weather Control
- Camera Settings
- Debug Screen

## Other Tools

- Omnipotent Building
- NPC Magnet
- Infinite Minions & Turrets
- Show Spawn Icons
- Lighting

Some interfaces can be dragged. To exit photo mode, click on the bottom center of the screen.
