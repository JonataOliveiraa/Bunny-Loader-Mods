# Fonte Ringbearer

Fonte de Pete Klassen: https://www.dafont.com/ringbearer.font

Licença: Gratuita para uso pessoal (texto em bl/license.md).

Gerada por tools/mods/port_fonts.py a partir do arquivo .ttf original, 3x (2x na mensagem de morte). A origem fica fora do Git, em build/font-sources/Ringbearer/.

As maiúsculas são enfeitadas e algumas ficam penduradas, como no logotipo do filme. ß, ©, ®, ™ e Ê continuam com a letra do jogo (nesta fonte eles são enfeites).
